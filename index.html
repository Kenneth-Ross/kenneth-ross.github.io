FORMULA SAE / ACTIVE DEVELOPMENT

Highlander Racing

A single vehicle program connecting simulation, synthetic perception, edge deployment, drive-by-wire control, and shop operations.

BOUNDARY
Simulation server → physical Orange Pi 5 Pro
EVIDENCE
RGB-D, IMU, and odometry streamed into the edge autonomy stack
SIL/HIL WORKFLOW

Simulation-to-edge autonomy

TECHNICAL NOTES

WHAT I BUILT

Gazebo runs cone-bounded tracks, a barebones Ackermann vehicle, and simulated RGB-D, IMU, and odometry. On the physical Orange Pi 5 Pro, YOLO estimates cone position and depth, an EKF filters IMU and odometry, and RTAB-Map supports localization before path planning.

WHAT IS VALIDATED

RGB, depth, IMU, and odometry leave the simulation server over Ethernet and reach the edge autonomy stack. The loop returns autonomous drive commands to Gazebo.

WHAT REMAINS OPEN

Controls hardware is not yet integrated. Physical closed-loop validation remains pending; the next validation is porting the autonomy command interface from the simulation sink to the separate vehicle-control interface.

POST-TRAINING STRATEGY / IN DEVELOPMENT

Known Blender scene geometry produces projected 2D ground-truth boxes. YOLO misses are grouped by failure mode—especially occlusion and long-range cones—then returned as targeted fine-tuning data before distillation, quantization, and RKNN edge deployment. Measured gains remain unvalidated.
